Gói web Canva Hub

Chỉ một file index.html, bên trong đã có đủ 149 thẻ, ảnh và số liệu. Không có thư mục, không có file đi kèm.

Đăng lên mạng

Cách 1, nhanh nhất: Netlify

  1. Mở app.netlify.com/drop.
  2. Kéo thả file index.html vào khung. Có thể phải tạo tài khoản miễn phí.
  3. Netlify trả về địa chỉ web. Mở lên là thấy Hub.

Cách 2: GitHub Pages

  1. Vào kho mã, bấm Add file rồi Upload files.
  2. Kéo file index.html vào, ghi đè file cũ nếu có. Bấm Commit changes.
  3. Đợi 1 đến 3 phút, mở địa chỉ web rồi bấm Ctrl+Shift+R (Mac: Cmd+Shift+R).

Các file cũ đang có trong kho mã (app.js, data.js, thư mục img...) không còn cần thiết và không ảnh hưởng, vì file mới tự chứa mọi thứ. Bạn có thể giữ hoặc xoá.

Trước khi công khai: nhờ bộ phận pháp lý xem lại việc lưu ảnh của người khác, và xin brand team xác nhận việc dùng logo Canva. Số lượt xem, tương tác là số lúc thu thập, không tự cập nhật. Bản này chưa có nút gửi bài.
